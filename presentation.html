02 — CONTEXT

The problem
we solve

Most mobile applications require a reliable authentication system. Marhaba provides a complete, secure, and elegant foundation.

05 — SECURITY

Reinforced
security

Security is not optional. Every layer of the application is protected.

🔑
bcrypt hashing (salt factor 10)
Passwords are hashed before storage. Never in plain text in the database or in JSON responses.
🎟️
Signed JWT with expiration
JWT tokens signed with a server secret, expiring after 7 days. Secret stored in environment variable.
📱
Expo SecureStore
The token is stored in iOS keychain / Android EncryptedSharedPreferences. Never AsyncStorage.
🛡️
Double route protection
Authenticate middleware on the backend + navigation guard on the frontend. Two barriers for unauthorized access.
🕵️
Opaque error messages
« Incorrect email or password » — same message for non-existent email and wrong password. Anti-enumeration.
✅
Server-side validation
validateRegister and validateLogin middlewares check fields and password length before the controller.

🔄 Authentication Flow

authController.js — Snippet 
const generateToken = (userId) => {
  return jwt.sign({ id: userId }, process.env.JWT_SECRET, {
    expiresIn: '7d'
  });
};

exports.login = async (req, res) => {
  const user = await User.findOne({ where: { email } });
  const isMatch = await bcrypt.compare(password, user.password);
  const token = generateToken(user.id);
  res.json({ user, token }); // password auto-excluded via toJSON()
};

🐻 Zustand Store

Minimalist global state with Zustand. Manages user, token, authentication state, and loading.

useAuthStore.js 
const useAuthStore = create((set) => ({
  user: null,
  token: null,
  isAuthenticated: false,
  isLoading: true,

  restoreSession: async () => {
    const token = await SecureStore.getItemAsync('token');
    if (!token) return set({ isLoading: false });
    const { data } = await api.get('/auth/me');
    set({ user: data.user, isAuthenticated: true });
  },

  login: async (token, user) => { /* ... */ },
  logout: async () => { /* ... */ },
}));

🔄 Navigation Flow

The root layout acts as a guard: it automatically redirects to the appropriate screen based on authentication state.

1️⃣
App launch
restoreSession() checks the token in SecureStore
2️⃣
Token found?
GET /api/auth/me call to validate token
3️⃣
Automatic redirection
Authenticated → (app)/home | No → (auth)/welcome
4️⃣
Axios Interceptor
Automatically injects the Bearer token into each request
