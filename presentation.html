Le problème que
nous résolvons

La plupart des applications mobiles nécessitent un système d'authentification fiable. Marhaba fournit un socle complet, sécurisé et élégant.

05 — SÉCURITÉ

Sécurité
renforcée

La sécurité n'est pas optionnelle. Chaque couche de l'application est protégée.

🔑
Hachage bcrypt (salt factor 10)
Les mots de passe sont hashés avant stockage. Jamais en clair dans la base ni dans les réponses JSON.
🎟️
JWT signé avec expiration
Tokens JWT signés avec un secret serveur, expirant après 7 jours. Secret stocké en variable d'environnement.
📱
Expo SecureStore
Le token est stocké dans le keychain iOS / EncryptedSharedPreferences Android. Jamais AsyncStorage.
🛡️
Double protection des routes
Middleware authenticate côté backend + guard de navigation côté frontend. Deux barrières pour un accès non autorisé.
🕵️
Messages d'erreur opaques
« Email ou mot de passe incorrect » — même message pour email inexistant et mauvais mot de passe. Anti-énumération.
✅
Validation côté serveur
Middlewares validateRegister et validateLogin vérifient les champs et la longueur du mot de passe avant le controller.

🔄 Flux d'authentification

authController.js — Extrait 
const generateToken = (userId) => {
  return jwt.sign({ id: userId }, process.env.JWT_SECRET, {
    expiresIn: '7d'
  });
};

exports.login = async (req, res) => {
  const user = await User.findOne({ where: { email } });
  const isMatch = await bcrypt.compare(password, user.password);
  const token = generateToken(user.id);
  res.json({ user, token }); // password auto-exclu via toJSON()
};

🐻 Zustand Store

État global minimaliste avec Zustand. Gère l'utilisateur, le token, l'état d'authentification et le chargement.

useAuthStore.js 
const useAuthStore = create((set) => ({
  user: null,
  token: null,
  isAuthenticated: false,
  isLoading: true,

  restoreSession: async () => {
    const token = await SecureStore.getItemAsync('token');
    if (!token) return set({ isLoading: false });
    const { data } = await api.get('/auth/me');
    set({ user: data.user, isAuthenticated: true });
  },

  login: async (token, user) => { /* ... */ },
  logout: async () => { /* ... */ },
}));

🔄 Flux de navigation

Le root layout agit comme un guard : il redirige automatiquement vers l'écran approprié selon l'état d'authentification.

1️⃣
Lancement de l'app
restoreSession() vérifie le token dans SecureStore
2️⃣
Token trouvé ?
Appel GET /api/auth/me pour valider le token
3️⃣
Redirection automatique
Authentifié → (app)/home | Non → (auth)/welcome
4️⃣
Intercepteur Axios
Injecte automatiquement le Bearer token dans chaque requête
